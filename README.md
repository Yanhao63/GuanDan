# 掼蛋蛋

面向四位朋友的在线掼蛋网页游戏。第一版只支持桌面浏览器，界面使用简体中文。

## 本地运行

```powershell
pnpm install
pnpm dev
```

当前已完成可交互的桌面端视觉原型，并开始接入独立规则引擎：现已覆盖单张、对子、三张、三带二、顺子、同花顺、四至十张炸弹、四王炸、动态级牌、红桃级牌百搭解释和炸弹比较，同时已实现两副牌生成与发牌、升级、打 A 三次失败降级、贡还牌基础判定、倒计时、报牌与掉线处置的纯规则。

仍在继续实现三连对、钢板、完整贡还交换流程、完整回合状态机、四人实时联机与机器人策略。当前测试命令：

```powershell
pnpm test
pnpm build
```

完整需求见 `docs/product-spec.md`，视觉规范见 `design/design-system.md`。
