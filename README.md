# 阿钊掼蛋

面向四位朋友的在线掼蛋网页游戏。第一版只支持桌面浏览器，界面使用简体中文。

## 本地运行

```powershell
pnpm install
pnpm dev
```

当前已完成可联机游玩的桌面端第一版主流程：权威服务端覆盖洗牌发牌、全部约定牌型、红桃级牌百搭、逆时针回合、接风、升级、打 A 三次失败降级、完整贡还牌、倒计时、报牌、掉线接管和跨副牌结算。

大厅与牌桌已经全部使用真实服务端状态，支持房主调整座位、机器人补位、每次出牌或“不要”后全桌保留结果 1.5 秒、机器人随后再等待 2.5 秒行动、昵称/重连码返回座位、动态级牌排序和“赖子”标记、手牌悬停让牌、快捷语和表情全桌同步、当前玩家指示、按玩家方向进入牌桌的出牌动画、贡牌全员公开 6 秒，以及保留最近两副牌和贡还牌的牌局历史。原创欢快背景曲、音效和优先选择自然女声的牌型播报均可独立调节，复杂牌型与炸弹会自动加快语速。Cloudflare Durable Objects 负责房间持久化、WebSocket 休眠恢复和个性化隐藏信息广播。当前测试命令：

```powershell
pnpm test
pnpm build
```

本地联机服务使用 `pnpm dev:worker`，正式部署使用 `pnpm deploy`。
