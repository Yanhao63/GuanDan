# 《阿钊掼蛋》桌面设计系统

状态：由用户批准的视觉概念提取，作为第一版前端实现规范。

## 2. 画布与缩放

- 基准画布：`1920 × 1080`，比例 `16:9`。
- 支持画布：1920×1080、2560×1440、3840×2160。
- 应用占满浏览器可视区域，核心牌桌保持 16:9 构图。
- 宽高比偏离 16:9 时使用深色胡桃木背景补边，不裁掉手牌、HUD 或主操作。
- 第一版不实现手机重排布局；桌面控件随视口使用统一比例变量缩放。
- 牌桌是开放主画布，不能改成卡片网格或多面板仪表盘。

| 中胡桃木 | `#3a281b` | 木纹高光与边缘 |
| 牌桌深绿 | `#07372c` | 主要呢面、弹窗主表面 |
| 牌桌暗绿 | `#05271f` | 阴影、次级按钮、抽屉 |

| 黄铜高光 | `#e1c778` | 聚焦、倒计时和选中状态 |
| 浅玉底色 | `#d7e5cf` | 主要按钮 |
| 玉石阴影 | `#9db9a2` | 主要按钮边缘和压下状态 |
| 主要文字 | `#f2ead8` | 正文、昵称、牌局状态 |

- 模态遮罩使用中性黑色透明层，不给牌桌增加其他色相。

## 4. 字体

- 品牌与大标题：`STSong`, `Songti SC`, `SimSun`, serif。
- 控件、昵称、牌局状态：`Microsoft YaHei`, `PingFang SC`, `Noto Sans SC`, sans-serif。
- 品牌字重：700；主要标题：700；正文与控件：500；辅助说明：400。
- 基准字号：
  - 品牌：40–48px；
  - 屏幕主标题：32–40px；
  - 弹窗标题：28–34px；
  - HUD：20–24px；
  - 玩家昵称：20–24px；
  - 主要按钮：22–28px；
  - 次要控件：16–20px；
  - 辅助说明：14–18px。
- 所有字号随画布比例统一缩放，但不得低于基准 1080p 的可读尺寸。

## 5. 空间、圆角与阴影

- 基础间距单位：`4px`；常用间距：8、12、16、24、32、48。
- 顶部 HUD 高度：约画布高度的 8%。
- 底部手牌与操作区：约画布高度的 31%。
- 圆角：小控件 8px；按钮 14px；弹窗 20px；牌桌外框 40px 以上。
- 黄铜描边：1–2px；主选中态允许额外 2px 柔和高光。
- 阴影保持向下、低扩散、低透明度，不使用漂浮玻璃卡片效果。

## 6. 组件家族

### 顶部 HUD

- 品牌、房间号、当前级牌、双方级数、牌局状态、声音和设置。
- 信息以细黄铜分隔线串联，不放入独立卡片。

### 玩家座位

- 组成：圆形水墨头像、昵称、角色/关系标签、剩余牌数、准备或断线状态、倒计时环。
- 上下座为队友，左右座为对手。
- 只有手牌不多于 10 张时显示准确剩余数量。
- 机器人名称必须带“机器人”并使用相同组件，不使用卡通机器人头像。

### 扑克牌

- 正面使用代码原生文字和花色符号，传统白色牌面、清晰左上角牌点。
- 红桃与方块使用扑克红；黑桃与梅花使用近黑。
- 牌背使用统一中式回纹/团花图案资产。
- 选中牌向上抬起并显示黄铜柔光，不能只改变颜色。
- 27 张手牌采用稳定重叠规则，牌点必须全部可见。

### 按钮

- 主要按钮：浅玉底、胡桃木文字、黄铜轮廓。
- 次要按钮：暗绿底、主要文字、黄铜轮廓。
- 危险或离开操作不使用刺眼红色，使用暗色次要按钮并通过文字表达。
- 禁用态保留形状，降低饱和度和文字对比。
- 必须实现 hover、focus-visible、active、disabled 状态。

### 模态弹窗

- 深绿主表面、胡桃木外框、细黄铜双线、克制阴影。
- 标题、说明、主要内容、底部动作形成稳定四段结构。
- 百搭、贡还牌、结算和断线状态复用同一弹窗骨架。

### 快捷语抽屉

- 从右侧打开，不遮挡中央牌局和本家手牌。
- 深绿列表、胡桃木外壳、黄铜分隔；快捷语与表情使用标签切换。
- 消息公开给全桌，不设计私聊或队友暗号入口。

## 7. 图标清单

所有图标使用自有 SVG，`currentColor` 着色，默认 2px 圆角线条；不使用文本字符代替方向图标。

- 扬声器：背景音乐/音效总入口；圆形黄铜外框。
- 齿轮：设置。
- 复制：复制邀请信息。
- 对话气泡：快捷语。
- 微笑：表情。
- 加号：加入机器人。
- 双向交换箭头：调整座位。
- 对勾：准备或选中。
- 单选圆点：百搭解释。
- 逆时针箭头：出牌方向提示。
- 关闭叉号：抽屉或弹窗关闭。
- 音乐、音效、麦克风：三个独立音量控制。

## 8. 动效

- 手牌选中：120–160ms 上移与阴影增强。
- 按钮 hover/active：120ms。
- 抽屉：180–220ms 横向进入。
- 模态：160–200ms 淡入并轻微上移。
- 倒计时：平滑圆环，不使用闪烁。
- 房主重连：玉石/黄铜呼吸环，1600–2200ms 循环。
- 遵循 `prefers-reduced-motion`，减少或关闭非必要动效。

## 9. 实现资产

- ImageGen：纯牌桌/木框背景、牌背图案、水墨头像。
- 代码原生：所有文字、扑克牌正面、按钮、表单、倒计时、状态、模态结构和图标。
- 不允许把完整视觉稿作为网页背景来伪装成 UI。

## 10. 主要交互路径

1. 输入昵称 → 创建或加入房间。
2. 房主调整座位、加入机器人、设置倒计时 → 四人准备 → 开始。
3. 选择手牌 → 必要时指定百搭解释 → 出牌。
4. 打开快捷语或表情 → 公开发送给全桌。
5. 双贡时头游选择贡牌 → 两位赢家分别还牌。
6. 本副结算 → 更新级数或打 A 失败次数 → 继续下一副。
7. 普通玩家断线 → 其他人继续至其回合 → 暂停 → 120 秒后机器人接管。
8. 房主断线 → 整局立即暂停 → 房主重连后继续。
