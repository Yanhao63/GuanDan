# 阿钊掼蛋验收记录

## 2026-08-31 · 后续牌局贡还牌流程修复

- 问题定位：抗贡原先在发完下一副牌后直接切换到出牌阶段，没有任何界面反馈，因此从玩家视角看起来像第三副跳过了进贡和还贡。
- 流程修复：单贡或双贡触发抗贡后，房间保留在贡还牌阶段 6 秒，四位玩家均看到“抗贡成功”、免交换说明和无秒数进度条；倒计时结束后才由上一副头游首出。
- 后续轮次保障：新增第二副结束进入第三副的完整双贡、贡牌公开、头游选贡、双方还贡回归测试；新增第五副触发抗贡、展示 6 秒后进入出牌的回归测试，逻辑不依赖固定局数。
- 自动检查：21 个测试文件、112 项测试全部通过；客户端 TypeScript 类型检查通过。
- 背景音乐：默认曲已替换为另一首原创 134 BPM、16 小节钢琴曲；右手演奏新旋律，左手使用分解和弦与根音/五度低音，没有电子鼓点。合成音色加入钢琴式击弦起音、不同速度衰减的泛音、轻微弦列非谐性与离键余音，并在输出前自动限制峰值。

## 2026-08-31 · 回合节奏与音频升级发布前验收

- 回合停顿：出牌与“不要”后均由服务端锁定回合 1.5 秒；展示期间 `currentSeat` 对所有客户端为空、操作按钮禁用，结束后才启动下一位的人类倒计时或机器人 2.5 秒思考时间。
- 浏览器计时：出牌后约 0.42 秒和 1.34 秒均没有下一位提示，约 2.07 秒已切换至机器人；“不要”在约 0.41 秒和 1.32 秒仍锁定，约 2.05 秒已切换。测量包含本机 WebSocket 往返时间。
- 结果展示：“不要”标记与出牌飞行动画从 0.6 秒延长为完整 1.5 秒；1920×1080 截图确认停顿中不高亮任何玩家、按钮禁用，结束后下一位高亮恢复。
- 背景音乐：默认曲重写为原创 142 BPM、16 小节完整循环，包含主旋律、高低段落、大小调和声、交替低音与轻打击节奏；结构测试确认不是单向爬音阶。
- 首次交互性能：背景曲改用异步启动、24 kHz 合成与内存缓存；实际牌桌首次选牌反馈约 292 毫秒，不再阻塞点击。
- 语音自然度：自动优先“晓晓”等在线自然女声，其次 Google 普通话，降低旧式桌面语音优先级；复杂牌型使用 1.22 倍语速、炸弹 1.3 倍语速。
- 播报断句：数字牌转换为中文单字并用空格短断词，取消顿号长停顿；木板、钢板、顺子、同花顺、三带二与炸弹文案回归通过。
- 自动检查：21 个测试文件、110 项测试全部通过；客户端、Worker 类型检查和正式生产构建通过。
- 浏览器运行：本地 Cloudflare 房间完成三机器人补位、90 秒限时开局、真实出牌与“不要”停顿验收，页面无框架错误覆盖层，控制台无警告或错误。
- 音频限制：验收用内置浏览器不提供系统 `speechSynthesis` 音色，因此已验证选音算法、生成文案、语速和音乐启动性能；最终女声听感仍取决于玩家浏览器实际安装的中文语音，需在常用 Chrome/Edge 中主观试听。
- 正式发布：已部署到 `https://guandan-dan.guandan-dan.workers.dev`，Cloudflare 版本为 `e797777e-1294-47e8-9f76-4e272a9bb9ed`；线上完成首页加载、房间创建和 WebSocket 入座验证，控制台无警告或错误。
